---
name: avoid-common-mistakes
description: Use this skill when preparing for tasks that involve coding, data analysis, or log parsing.
---
- Ensure all required files are created before running tests or executing commands.
- Verify that the module or package names are correct and accessible in the current environment.
- Check that all functions and methods have the necessary type annotations as per the project guidelines.
- Confirm that any modifications to test files do not alter the original files in the tests directory.
- Review the expected output format and ensure compliance with specifications before finalizing results.
- Maintain a changelog to document all changes made during the task, including bug fixes and feature updates.
- Validate that all data transformations and calculations are performed correctly and yield expected results.
- Ensure that all required test cases are implemented and that they cover the necessary scenarios.
- Regularly run tests to catch errors early in the development process.
- Document any assumptions or decisions made during the task to provide context for future reference.
