---
name: handle-errors-properly
description: Use this skill when working with data processing or log parsing tasks.
---
- Implement error handling to manage exceptions gracefully during data processing.
- Log errors with sufficient detail to facilitate debugging and resolution.
- Ensure that the program can recover from non-critical errors without crashing.
- Validate input data before processing to catch potential issues early.
- Use try-except blocks to handle specific exceptions that may arise during execution.
- Provide meaningful error messages that can guide users in troubleshooting.
- Test the error handling logic to ensure it behaves as expected under various scenarios.
- Document known issues and their resolutions to assist future users or developers.
- Regularly review and update error handling strategies based on new insights or changes in requirements.
- Encourage the use of unit tests to cover error scenarios and validate handling mechanisms.
