---
name: validate-output-structure
description: Use this skill when generating output files or data structures.
---
- Confirm that the output file structure matches the specified format exactly.
- Ensure all required fields are present in the output, including any nested structures.
- Validate data types for each field to ensure they conform to expected types (e.g., integers, strings).
- Check for any missing or extra fields that could lead to validation errors.
- Use automated tests to verify the output structure against expected schemas.
- Review the output for consistency, especially when aggregating or summarizing data.
- Ensure that any transformations applied to the data are correctly reflected in the output.
- Document the output generation process to clarify how the final structure was achieved.
- Test the output with sample data to ensure it meets all requirements before submission.
- Keep a checklist of output requirements to ensure nothing is overlooked during the final review.
